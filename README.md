# This is a Title

This is a personal project of mine to recreate an enigma machine used by the Germans to both encrypt and decrypt their military's messages during the Second World War. It was infamously difficult
to crack until some **nerds** in the UK finally did so.

You may say "it's a piece of crap," and honestly, it is; I don't really care since this was just for fun. I don't plan on upgrading this anytime soon, so to each their own.
